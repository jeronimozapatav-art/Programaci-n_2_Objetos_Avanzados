02. Fundamentos y Dominio de POO

Fundamentos

Programación Orientada a Objetos Básica

Comprensión del modelado del mundo real a través de estructuras lógicas fundamentales:

  • ▹ Clases y Objetos: Plantillas para la creación de instancias con atributos y métodos.
  • ▹ Encapsulamiento: Ocultamiento de datos internos mediante getters, setters y visibilidad (público/privado).
  • ▹ Abstracción: Identificación de características esenciales reduciendo la complejidad del sistema.
Programación 2

POO Avanzada

Aplicación de conceptos avanzados para construir software extensible, modular y reutilizable:

  • ▹ Herencia y Polimorfismo: Reutilización de código mediante jerarquías y sobreescritura de métodos.
  • ▹ Interfaces y Clases Abstraídas: Definición de contratos y comportamiento estándar para módulos.
  • ▹ Manejo de Excepciones y Colecciones: Control de errores en tiempo de ejecución y gestión avanzada de estructuras de datos.
