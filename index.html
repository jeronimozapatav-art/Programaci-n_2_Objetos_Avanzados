01 // IDENTIDAD

Sobre mí

Perfil académico

Soy estudiante de Desarrollo de Software y durante mi proceso académico he venido fortaleciendo mis conocimientos en programación, especialmente en Programación Orientada a Objetos y desarrollo de aplicaciones utilizando Java.

Objetivo

Este portafolio tiene como propósito presentar el proceso de aprendizaje, las actividades desarrolladas y los diferentes entregables realizados durante las materias relacionadas con programación orientada a objetos.

02 // FORMACIÓN

Contenido de las Materias

En esta materia se trabajan los fundamentos de la Programación Orientada a Objetos y la construcción de programas utilizando clases y objetos.

Clases y objetos

Creación y utilización de clases, atributos, métodos y objetos.

Encapsulamiento

Protección de los atributos y control del acceso mediante métodos.

Abstracción

Identificación de las características y comportamientos esenciales.

Herencia

Reutilización de código mediante relaciones entre clases.

Polimorfismo

Diferentes comportamientos mediante una misma interfaz o referencia.

Java

Implementación práctica de los conceptos de POO utilizando Java.

En esta materia se profundizan los conceptos de Programación Orientada a Objetos mediante el desarrollo de sistemas más estructurados y aplicando buenas prácticas de diseño.

SOLID

Aplicación de principios para desarrollar software más mantenible y organizado.

Asociación

Relaciones entre diferentes clases dentro del diseño del sistema.

Agregación

Relación donde una clase contiene o agrupa objetos de otras clases.

Composición

Relación fuerte entre objetos que forman parte de una estructura.

Sobrecarga

Utilización de varios métodos con el mismo nombre y diferentes parámetros.

Sobrescritura

Redefinición del comportamiento de un método heredado.
