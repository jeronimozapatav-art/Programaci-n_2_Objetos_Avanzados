Herencia y polimorfismo

Aplicación de herencia entre clases, reutilización de código y utilización del polimorfismo mediante métodos.

En esta materia se trabajan conceptos avanzados relacionados con el diseño y desarrollo de software utilizando Java.

Principales conceptos:
  • 1. Herencia y jerarquía de clases: Reutilización de código mediante superclases y subclases.
  • 2. Polimorfismo: Permite que diferentes objetos respondan de distintas maneras ante una misma operación.
  • 3. Interfaces y clases abstractas: Definición de estructuras y comportamientos comunes para diferentes clases.
  • 4. Colecciones y excepciones: Manejo de listas, conjuntos, mapas y control de errores mediante excepciones.
